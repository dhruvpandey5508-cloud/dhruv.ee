# Dhruv Pandey — Engineering Exploration E-Portfolio

A compact student portfolio for GitHub Pages.

## Publish
1. Create a public GitHub repository (for example `engineering-exploration-portfolio`).
2. Upload `index.html` and the complete `assets` folder (keep the folder structure unchanged).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Wait for deployment. GitHub will show your live Pages URL in Settings → Pages.

All images and MP4 files are included in `assets/`; keep them in the repository so the media loads on the published site.

Note: GitHub Pages serves a website built from HTML/CSS. Visitors do not need to download or open the source files; they simply visit the published URL.
